# Relatos de jugadores

Archivo editable para revisar manualmente los textos que usa el generador de relatos de jugadores.

Instrucciones:
- Editar el texto despues del `|`.
- Mantener el ID de la izquierda para poder actualizar el codigo despues.
- Mantener los placeholders si siguen haciendo falta: `{jugador}`, `{zona_fuerte}`, `{zona_debil}`.
- Los grupos indican en que parte del relato se usa cada frase.
